Za to so PyGAD callback funkcije zelo primerne. Predlagam, da uporabiš on_start, on_fitness, on_crossover, on_mutation in on_generation.
1. Kaj točno meriti?

Predlagam naslednje metrike:
Metrika	Kaj meriš
Initialization time	Čas generiranja začetne populacije
Fitness evaluation time	Čas izračunavanja fitness funkcije
Crossover time	Čas izvajanja križanja
Mutation time	Čas izvajanja mutacije
Generation time	Čas ene generacije
Best fitness	Najboljši fitness v posamezni generaciji
Average fitness	Povprečni fitness populacije

Posebej pomembno je, da meriš tudi začetni fitness populacije, še preden se začne prva generacija. Tako boš lahko pokazal, ali greedy inicializacija že na začetku ustvari boljše rešitve.
2. Kako implementirati merjenje s PyGAD callbacki?

Najprej ustvariš razred, ki bo zbiral podatke med izvajanjem algoritma.

Uporabil bi time.perf_counter(), ker je primeren za natančno merjenje trajanja operacij.
import time
import numpy as np

class GAMetrics:

    def __init__(self):
        self.fitness_history = []
        self.avg_fitness_history = []

        self.generation_times = []
        self.fitness_times = []

        self.crossover_times = []
        self.mutation_times = []

        self.generation_start = None
        self.fitness_start = None

        self.total_start = None

    def on_start(self, ga_instance):
        self.total_start = time.perf_counter()
        self.generation_start = time.perf_counter()

    def on_fitness(self, ga_instance, population_fitness):

        best_fitness = np.max(population_fitness)
        avg_fitness = np.mean(population_fitness)

        self.fitness_history.append(best_fitness)
        self.avg_fitness_history.append(avg_fitness)

    def on_crossover(self, ga_instance, offspring):

        # Callback se izvede po crossover operaciji.
        pass

    def on_mutation(self, ga_instance, offspring):

        # Callback se izvede po mutation operaciji.
        pass

    def on_generation(self, ga_instance):

        generation_time = time.perf_counter() - self.generation_start

        self.generation_times.append(generation_time)

        self.generation_start = time.perf_counter()

    def on_stop(self, ga_instance, last_population_fitness):

        self.total_time = time.perf_counter() - self.total_start

Pomembna podrobnost: on_crossover in on_mutation se izvedeta po zaključku operacije. Zato z njima neposredno ne moreš izmeriti časa samega crossoverja oziroma mutationa. Za to potrebuješ ovijalno funkcijo (wrapper) okoli operatorja.

Enako velja za fitness: čas izračuna meriš neposredno znotraj fitness funkcije.
3. Merjenje časa fitness funkcije

Svojo obstoječo fitness funkcijo lahko oviješ tako:
def fitness_func(ga_instance, solution, solution_idx):

    start = time.perf_counter()

    fitness = calculate_fitness(solution)

    elapsed = time.perf_counter() - start

    metrics.fitness_times.append(elapsed)

    return fitness

calculate_fitness() predstavlja tvojo obstoječo implementacijo.

Tako dobiš čas posameznega izračuna fitness funkcije.

Pomembno: PyGAD lahko fitness izračune tudi ponovno uporabi, zato število klicev fitness funkcije ni nujno enako številu vseh rešitev v vseh generacijah.

5. Kako izmeriti crossover in mutation?

Ker želiš primerjati izvajanje posameznih faz, lahko uporabiš tudi časovne oznake med callbacki.

Na primer:
class GAMetrics:

    def __init__(self):
        self.crossover_times = []
        self.mutation_times = []

        self.stage_start = None

    def on_parents(self, ga_instance, selected_parents):
        self.stage_start = time.perf_counter()

    def on_crossover(self, ga_instance, offspring):
        elapsed = time.perf_counter() - self.stage_start
        self.crossover_times.append(elapsed)

        self.stage_start = time.perf_counter()

    def on_mutation(self, ga_instance, offspring):
        elapsed = time.perf_counter() - self.stage_start
        self.mutation_times.append(elapsed)

Dodaš še:
on_parents=metrics.on_parents,

Tako približno izmeriš čas med posameznimi fazami. Vendar upoštevaj, da meritve vključujejo tudi nekaj režije PyGAD in callbackov. Če želiš natančen čas samega operatorja, uporabiš časovno merjenje neposredno v lastnem crossover oziroma mutation operatorju.
